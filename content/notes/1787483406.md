### QCADesigner-E

QCADesigner-E is an extension of **QCADesigner 2.0.3**, developed at the University of Bremen. It adds power-dissipation estimation for **Quantum-dot Cellular Automata (QCA)** circuits, based on the theoretical work of Timler, Lent, and others. The extension was presented in [2](https://doi.org/10.1109/TCAD.2018.2789782).

The power-estimation functionality is integrated as an additional simulation module based on the **Coherence Vector Simulation Engine (CVSE)**. QCADesigner-E remains fully compatible with QCA designs created using QCADesigner 2.0.3.

QCADesigner is widely used by researchers working on QCA architectures for designing, simulating, and verifying cellular automata circuits. Its standardized environment makes it possible to model QCA logic gates and interconnects while performing timing analysis. QCADesigner-E extends this workflow by allowing researchers to estimate power dissipation and evaluate the energy characteristics of their designs.

### Linux AppImage

I have repackaged **QCADesigner-E as an AppImage**, making it possible to run the application on a wide range of Linux distributions without requiring users to manually install its dependencies or build the software from source.

The resulting AppImage is portable and distribution-independent, providing a straightforward way to run QCADesigner-E on modern Linux systems.
