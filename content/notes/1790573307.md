### Introducing Newsy: A Newsletter Platform Powered by GitHub Issues

Newsy is a newsletter platform inspired by projects like [Utterances](https://utteranc.es), [Giscus](https://giscus.app), and [Gitalk](https://gitalk.github.io)  projects that reimagined commenting on static sites by using GitHub Issues as the backend.

Newsy takes the same idea and applies it to newsletters.

Instead of relying on a traditional email marketing service, maintaining a separate mailing list, or paying for SMTP APIs, your newsletter can live alongside your code in a GitHub repository.

Newsy is built around a simple idea: **your content and subscriber infrastructure shouldn't have to live somewhere completely separate from your project.**

It aims to remove much of the overhead that comes with traditional newsletter platforms while keeping everything close to the tools developers already use.
